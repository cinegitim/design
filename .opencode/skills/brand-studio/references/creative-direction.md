# Creative Direction — Three Different Visual Worlds

How to turn one inferred brief into 3 directions that are genuinely different.

## The rule

Directions must differ in **central concept AND visual grammar**. If you can swap palettes between A and B and nothing breaks, they are the same direction — redo them.

Visual grammar = logo logic + composition/grid + pattern language + iconography + imagery language + texture/material + type character. Change at least 4 of these per direction.

## Differentiation matrix (pick one row per direction, never repeat a row)

| Axis | World 1 example | World 2 example | World 3 example |
|---|---|---|---|
| Concept source | Journey / passage (bridge, threshold, ascent) | Scholarship / craft (atelier, manuscript, lab) | Dialogue / exchange (correspondence, mentorship) |
| Logo logic | Wordmark-led with one constructed letterform incident | Symbol-led: abstract device derived from concept (not literal) | Monogram / ligature system |
| Grid | Editorial 12-col, generous margins, asymmetric | Modular geometric, centered, badge-compatible | Fluid editorial + timeline axis |
| Pattern | Topographic / route lines | Archival rules / annotation marks | Correspondence marks (stamps, indexes, seals — abstracted) |
| Imagery | Documentary campus life, natural light | Still-life study objects, tactile paper/stone | Portrait-led mentorship moments |
| Texture | Paper grain, letterpress | Stone / ink / brush restraint | Fabric / woven thread |
| Type character | Humanist serif display + grotesk text | Neoclassical serif + mono accents | Contemporary grotesk + scholarly serif italic |

For a Turkish-education → Asian-universities brand, strong concept pools: *threshold/passage, scholarly craft, mentorship correspondence, cartography of study paths, translation between scripts*. Weak pools: flags, maps-as-logos, graduation caps, globes.

## 14-point direction spec (every direction defines all of these)

1. **Central concept** — one sentence, e.g. "The threshold: education as a deliberate crossing, designed with calm authority."
2. **Logo logic** — what the mark IS and why (construction idea, not just shape).
3. **Wordmark character** — case, weight, spacing, distinctive cut/join; fallback stack.
4. **Typography** — display + text + accent/mono; scale ratio; sample settings rendered on the board.
5. **Palette** — 1 primary, 1–2 secondary, neutrals, 1 accent; hex + role + proportion (60/30/10); contrast-checked pairs.
6. **Composition/grid** — columns, margins, hierarchy rule, signature layout move.
7. **Recurring graphic devices** — 1–2 ownsable devices (rule, frame, seal, thread, gate).
8. **Pattern language** — construction + density + where it lives / where it never lives.
9. **Iconography** — stroke, corner, weight; 3 sample icons drawn in the same logic.
10. **Photography/illustration language** — subject, light, crop, color treatment, what is forbidden.
11. **Texture/material language** — paper, ink, fabric, metal; print finishes if relevant.
12. **Digital behaviour** — hero logic, button/link language, card rhythm, responsive move.
13. **Print behaviour** — paper, finishes, cover system, inside-page rhythm.
14. **Motion behaviour** — one signature transition (e.g. threshold wipe, annotation draw-on, thread pull) + reduced-motion fallback.

## Naming

Give each world a proper name + one-line promise. Never "Option 1/2/3" or "Modern/Minimal/Premium".

## Cultural research (brief, mandatory when relevant)

2–5 lookups: competitor identities, audience trust signals, color/type connotations in TR + target Asian markets, premium-education codes. Note in one line per direction what the research changed. Avoid stereotypes; never lift national symbols literally.

## Swap test (gate before building boards)

Describe A in one paragraph, then swap its palette with B. If the description still fits, kill one and replace it. Record the test result in one line.

## Visual source of truth (fidelity transfer)

A selected direction's generated image stays the VISUAL SOURCE OF TRUTH until the production implementation proves it preserves the source's aesthetic character. Never reduce a direction to abstract rules first; "concept captured" ≠ "design captured". The full fidelity pipeline (Visual DNA → reconstruction → side-by-side review → human approval → canonicalization) lives in `identity-development.md`.
