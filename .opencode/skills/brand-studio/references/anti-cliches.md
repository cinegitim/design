# Anti-Clichés — What to Avoid and What to Do Instead

Generic AI branding fails the same way. Avoid these defaults unless genuinely justified in one written sentence tied to the concept.

## Banned defaults (require written justification)

| Cliché | Why it fails | Do instead |
|---|---|---|
| Globes / maps-as-logos | Says "international" with zero ownability; unreadable small | Abstract the *idea* (threshold, route, correspondence) into geometry, grid, or pattern |
| Graduation caps, books, pencils | Category wallpaper for education; every competitor has one | Scholarly *craft* signals: archival rules, annotation marks, manuscript margins, seal logic |
| Handshakes, swooshes, upward arrows | Stock-metaphor optimism, no brand memory | One constructed letterform incident or monogram with a single distinctive cut/join |
| Meaningless geometric symbols (hexagon + node, circle + orbit) | Reads as generic SaaS/tech | Derive the symbol from the concept sentence — if you can't explain the derivation, kill it |
| Random gradient blobs / mesh gradients as identity | Decorative filler, unprintable, unownable | Flat, print-honest color with one disciplined texture (paper grain, ink, weave) |
| Flags / national colors used literally | Stereotype risk, political load, unscalable | Cultural *translation*: script contrast, seal/stamp abstraction, color research without copying flags |
| Overused node/network marks, leaves, generic luxury spacing | Trend-chasing, undifferentiated | Category codes done with restraint + one differentiation signal (see below) |

## Category codes vs clichés (education example)

- Expected trust signals: calm authority, editorial typography, clear hierarchy, documentary (not stock) imagery, legible small-size mark.
- Differentiation signals (pick 1–2): a threshold device, an annotation/margin system, a correspondence/index pattern, a bilingual-script ligature idea.
- Purchase context decides touchpoints: website hero, brochure, social proof graphics, event signage, presentation decks — not random business cards.

## Justification test

If you use a risky motif, write: "This [motif] is justified because [concept link] and it survives [small-size / mono / cultural] test by [reason]." No sentence → remove it.

## Language test

Never describe work as "premium / modern / innovative" without tying it to a visible choice: "premium via [paper + restrained palette + editorial grid + generous whitespace]", not adjectives alone.
