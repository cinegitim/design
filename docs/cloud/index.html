Ne kuruldu?

  • Codex’e uygun repo skill’leri; mevcut Brand Studio metodolojisine tek kaynaktan erişim.
  • Python 3.12 / Node 22 kurulum tarifi; sabit Python paketleri ve Playwright lockfile.
  • İlk taşınabilir üretim tarifi: beş slaytlı Launch Creative 02. Mevcut teslim bu altyapı değişikliğinde yeniden üretilmedi.
  • Bağımsız denetim: kanonik logo hash’leri, PNG yapısı/boyutu, kaynak metni, asset bağlantıları, paket bütünlüğü ve bilinen credential örüntüleri.
  • Yerelde benzersiz 12 yaratıcı/tarihsel dosya korundu. Toplam 253 dosyanın checksum/sınıflandırma kaydı tutuldu; kopyalar ve runtime logları tekrar yüklenmedi.

Hesapta yapılacak tek seferlik kurulum

  1. ChatGPT Work/Codex → Work in → Cloud → Create environment.
  2. cinegitim/design reposunu bağlayın; Python 3.12 ve Node 22 isteyin.
  3. Install script: bash studio/cloud/setup.sh.
