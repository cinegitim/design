Ne kuruldu?

  • Codex’e uygun repo skill’leri; mevcut Brand Studio metodolojisine tek kaynaktan erişim.
  • Python 3.12 / Node 22 kurulum tarifi; sabit Python paketleri ve Playwright lockfile.
  • İlk taşınabilir üretim tarifi: beş slaytlı Launch Creative 02. Mevcut teslim bu altyapı değişikliğinde yeniden üretilmedi.
  • Bağımsız denetim: kanonik logo hash’leri, PNG yapısı/boyutu, kaynak metni, asset bağlantıları, paket bütünlüğü ve bilinen credential örüntüleri.
  • Yerelde benzersiz 12 yaratıcı/tarihsel dosya korundu. Toplam 253 dosyanın checksum/sınıflandırma kaydı tutuldu; kopyalar ve runtime logları tekrar yüklenmedi.

Hiç proje dosyası bilgisayara indirmeden?

Uzak çalışma alanıyla evet; yalnız GitHub repo bağlantısıyla tam üretim hayır. GitHub depolar ve sürümler; font, Python, Chromium, görsel araçlar ve ZIP üretimi için bir çalışma ortamı gerekir. OpenCode sunucusu ve dosyaları uzakta çalışırsa bilgisayarınızda proje checkout’u tutmanız gerekmez.

Basit dosya düzenleme/PR işlemleri GitHub API ile checkout olmadan yapılabilir. Bu, tam render/görsel toolchain’i değildir. Yerel arayüzün önbellek veya oturum kaydı tutması da proje dosyası indirmekten ayrı bir konudur; sıfır yerel veri garantisi verilmez.
