Yerelde geçici çalış, GitHub’da koru

Seçilen yöntem ücretli VM veya gerçek RAM disk gerektirmez. OpenCode dosyaları geçici disk alanında işler; Work/Codex kendi bulut alanını kullanır. GitHub’da aynı kaynaklar, onaylı kimlik ve iş kayıtları saklanır. Klasör sayısı değil, rutin işlemleri otomatikleştirmek token tasarrufuna yardımcı olur.

İş tamamlanınca PR açılır; exact HEAD’in zorunlu GitHub denetimleri incelenir. Teknik hata ve çakışmalar kayıpsız düzeltilir, yeni commit tekrar denetlenir. Kontroller geçip esaslı blocker kalmadığında ek merge onayı istenmeden merge edilir; yayın doğrulanır. Kullanıcının belirli PR’ı bekletme talimatına uyulur. CI, estetik veya logo onayı değildir.

Ardından temizlik komutu exact remote commit’i, bağımsız indirilen dosya byte’larını, temiz çalışma ağacını ve aynı PR HEAD’inde başarılı denetimi kontrol eder. Gönderilmemiş, değiştirilmiş veya ignored özgün dosya varsa temizlik durur. Yalnız manager-owned yeni iş clone’u ve Git object store’u temizlenir; OPEN veya MERGED PR desteklenir. Cleanup merge yapmaz.

Bu bir zamanlı silme servisi değil, açık tamamlanma komutudur. Geçici klasör, OpenCode oturum kaydı veya araç önbelleğiyle aynı şey değildir; sıfır yerel veri garantisi verilmez. Mevcut eski proje klasörlerini silmek ayrı izin gerektirir.
