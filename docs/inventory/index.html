Arşivleme kararlarından önce tüm GitHub üretim geçmişini, sürümlerini ve dosya bağımlılıklarını kategorik olarak incele. Buradaki işaretlemeler hiçbir üretimi kaldırmaz.

—İzlenen Git dosyası

Arşive taşınmış hiçbir içerik yok. “Aday” bir öneridir; emeklilik kararı değildir. Onaylı logo ve kimlik kaynakları, tasarımların ortak varlıkları, manifestler ve sistem dosyaları korunur. Başka depoya aktarım ancak seçili dosya ve bağımlılıkları SHA ile doğrulandıktan sonra yapılabilir.

Bir kayıt seç

Soldan üretim seçerek bütün dosyalarını, sürüm izlerini, kaynak doğrulama SHA kimliklerini ve koruma notlarını görebilirsin.

Kayıt sınıflaması: İlk arşiv adayı = eski/deneysel üretimleri karşılaştırmak için işaret. Tek tek incelenecek = kullanım, bağlantı ve sürüm kontrolü gerekiyor. Üretim/gözden geçirme = çıktısı mevcut, insan onayı varsayılmıyor. Korumalı kaynak = iş akışının veya marka kimliğinin bağlı olduğu dosyalar.

Kaynak: cinegitim/design. Envanter kapsamı: bütün Git blob dosyaları; Git geçmişinde artık bulunmayan önceki commitler, tarayıcı localStorage'ındaki yayımlanmamış sürümler ve harici servislerde saklanan dosyalar bu kayıtların dışında olabilir.
