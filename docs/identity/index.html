H-02 · Küçük dijital kullanım

Yeni logo üretmiyoruz: H-02'nin aynı vektörünü orantılı olarak küçültüyoruz. Varsayılan 360–480px; dar kullanımda 320px'e kadar. Daha küçük alanlarda yalnızca V-01 mühür. C-03/D-04 artık onaylı seçenek değildir.

Küçültme öncesi/sonrası mühür–yazı oranları aynıdır. Başka seal, font, yeniden çizilmiş sözcük veya değişmiş viewBox kullanılmaz. İngilizce ince satırın okunabilirliğini gerçek boyutta kontrol et.
