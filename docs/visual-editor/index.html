Mevcut üretimini düzenle.

Önce prompt ile üretilmiş HTML/CSS karuselini kullan. Başlıkları, fotoğraf alanlarını ve renkleri Visual Editor’de değiştirebilirsin. Kayıt onayınla yeni v2, v3 klasörleri yerel bilgisayarında oluşturulur.

Tarayıcıda düzenle ↗Yerel uygulamayı aç ↗Kurulum ve kayıt rehberi
Bu sayfa dosya kaydetmez. Tarayıcı editörü yalnızca tarayıcıya veya seçtiğin klasöre kaydeder. Yerel uygulamayı tercih edersen Mac'inde başlatılmış olmalı ve ürün daha önce yerel ürün listesine kaydedilmiş olmalıdır. Aksi hâlde yerel bağlantı açılmayabilir veya ürün bulunamayabilir. Site GitHub’a sessizce yazmaz.

Nasıl çalışır?

  1. Önce mevcut HTML/CSS üretiminin kaynakları ve PNG’leri tamamlanır.
  2. İsteğe bağlı register-output işlemi ürünü yerel uygulamaya kaydeder.
  3. Visual Editor ile düzenlemeyi yaparsın.
  4. Kaydet dediğinde onay sorulur; kayıt ayrı versions/vN/ klasörüne yapılır.
  5. Render ve onay kontrolleri tamamlanmadan hiçbir sürüm yayımlanmış sayılmaz.

Özgün prompt üretimi korunur. Site sadece giriş noktasıdır; aktif düzenleyici yerel uygulamadır.
