Fotoğraf düzenleme

Orijinal görsel kullanılıyor.
Yalnızca PNG, JPEG veya WebP. Fotoğraf tarayıcıda küçültülür; sunucuya yüklenmez. Gömülü görsel JSON arşivi ve indirilen HTML ile taşınır. Büyük fotoğraflar sürüm depolama limitini doldurabilir.
Kadraj ayarları kaynak dosyaya dokunmaz. Daha önce kaydedilmiş özgün fotoğrafı “Orijinaline dön” ile geri alabilirsin.
