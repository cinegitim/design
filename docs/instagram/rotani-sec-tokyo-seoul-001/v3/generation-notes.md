# Generation notes — Rotanı Seç #001 / V2

## Production method

V2 is produced by a measured, deterministic pipeline rather than hand-placed
coordinates:

1. **Composition** — `templates/*.html` with `templates/campaign.css` lay out six
   slides using CSS Grid and Flexbox. Critical text lives in structural
   containers with internal padding and 56–58px outer margins.
2. **Measurement** — `extract-backgrounds.mjs` opens each template in headless
   Chromium, forces layout stability, and measures every `[data-copy]` block:
   its client rect, its parent container, its computed padding, and the
   per-character runs that make up each visual line (x, top, height, font size,
   weight, colour, letter spacing, line height).
3. **Composition** — `build.py` recomposes each slide as an editable SVG: the
   measured clean photograph layer, then one `<text>` element per measured run,
   positioned from real font metrics
   (`baseline = lineTop + (lineHeight − fontSize)/2 + fontSize × 0.75`),
   with `xml:space="preserve"` so inline-span spacing survives.
4. **Rendering** — `render.mjs` opens the composed SVG at 1080×1350, exports the
   final PNG plus a 375×469 mobile preview, and runs the geometry audit.
5. **Verification** — `verify_and_package.py` re-checks exact copy, geometry,
   canonical lockups, logo contrast, dimensions, profile, and assembles the
   contact sheet, V1/V2 comparison, previews, manifest and ZIP.

## Image and model calls

- **2 image generations** via `gen_edit_image_free` (Pollinations): the two
  illustrative housing interiors on slide 05. Both are disclosed as
  illustrative and never presented as documentary photography.
- **0 image edits.**
- 19 photographic assets total: 12 carried over from V1, 5 newly licensed
  Wikimedia Commons files (Songdo Underwood Memorial Library, Songdo Central
  Park, Sinchon station sign, Shinjuku night, Nakano Broadway), and the 2
  disclosed illustrative interiors.
- No text, wordmark or logo was ever generated by an image model.

## Locked identity

- `D-04/dark` on slide 01 (dark cinematic ground)
- `D-04/light` on slides 02–05 (light paper grounds)
- `H-02/dark` on slide 06 (dark finale) at 540px, above its 528px minimum

All are unmodified manifest-listed canonical SVGs, verified by hash. An
automated contrast gate samples the true ground — including the lockup's own
opaque chip — and rejects a variant that does not suit it.

## Environment note

The pinned `studio/cloud/setup.sh` requires Python 3.12, which is unavailable on
this macOS host. Rendering used the repository-pinned Playwright 1.56.1 module
with installed Google Chrome and the repository Jost variable font. No dependency
is committed, and `node_modules` stays untracked.
