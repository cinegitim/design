# Wordmark reference archive

**EXPERIMENTAL / NOT FOR PRODUCTION.**

This folder contains historical measurement, tracing, vector, weight and
alignment work. Candidate B was rejected. A / Jost 700 was not approved. W1/W2/W3,
WU, smooth, A/B, weight-study outputs and all alternative alignments are retained
only to document the process.

Production must not use any SVG or PNG from this folder. Use only complete SVGs
listed in `brands/asyada-egitim/assets/lockups/canonical-lockups.json`, or the
locked seal `brands/asyada-egitim/assets/v01-canonical.svg` for seal-only use.

Run `python3 studio/tools/verify_asyada_canonical_lockups.py` before publishing
any Asya'da Eğitim branded output.
