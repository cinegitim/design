# Data Atlas · Information-first carousel

**Status: review-only.** This is a proposed *visual language*, not an identity
change, approved template or permission to invent facts.

Use for verified comparisons, timelines, how-to sequences, statistics and
evidence-led education guidance. Source of truth: [style.json](style.json).

A typical information journey uses an overview, data/evidence, comparison and
action. Typography stays Jost; palette and SVG lockups use only canonical
SHA-256 verified Asya’da Eğitim assets. The style's distinction is its
information architecture (grids/rails/matrices), not color tweaks.

Presets: **Metrics Overview**, **Timeline Path**, **Comparison Led**.
Variation axes control data density, structure, evidence focus, cover,
media role and sequence.

Do not invent admission deadlines, tuition, prices, rankings or university
images. Real HTML/CSS/SVG + mobile-size visual inspection are required.
A selected preset is a production input, never creative or publication approval.
