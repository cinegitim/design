8 yaratıcı bölge

Görsel keşiften önce müşteri seçimi için. Logo yok, görsel yok, skor yok — yalnızca tarifler.

01

Contemporary Ink

CORE IDEATek kontrollü jest hafızası: basınç, ritim, negatif alan; disiplinli sistem içinde işlenmiş tek düzensizlik.

MARK HYPOTHESISSınırla kesilmiş tek çizgi-türevi soyut işaret; resim değil.

TYPE / COLORSerif display + sakin sans; mürekkep + kâğıt + tek mineral vurgu.

ASIAN SOURCEKaligrafik basınç-ritim ve boşluk kompozisyonu (motif yok).

STUDENT / PARENTKişisel, canlı / kültürlü, güvenilir.

MAIN RISKRestoran/fake-kaligrafi kayması. ASLA: sahte karakter, literal fırça resmi, oryantal dekor.

02

Editorial East

CORE IDEADoğu Asya editoryal disipliniyle tipografi-öncül kimlik: asimetri, indeks, ince çizgi, ölçek sürprizi.

MARK HYPOTHESISBelki simgesiz; küçük ikincil işaret + baskın kelime-mark.

TYPE / COLORYüksek yazarlı serif/sans gerilimi; kâğıt nötrler + derin editoryal vurgu.

ASIAN SOURCEEditoryal kompozisyon mantığı: dikey ritim, indeks, marj disiplini.

STUDENT / PARENTZeki, içeriden / ciddi, ücrete değer.

MAIN RISKSoğuk/müze mesafesi. ASLA: moda dergisi, müze kimliği, kültürel pozisyonsuz İsviçre ızgarası.

03

Modern Seal

CORE IDEAMührün otoritesi çağdaş geometriyle: sıkıştırma, sınır, baskı izi, pozitif/negatif, işçilikli kusur.

MARK HYPOTHESISSıkışık alanlı, soyut iç bölünmeli imza; mühür mantığı, mühür grafiği değil.

TYPE / COLORSağlam serif/grotesk; mühür-kırmızısı ailesi + mürekkep + kâğıt.

ASIAN SOURCEGüven aracı olarak mühür kültürü mantığı.

STUDENT / PARENTGururlu, resmi aidiyet / maksimum kurumsal güven.

MAIN RISKDevlet-emblema sertliği / sahte-Çin-mührü pastişi. ASLA: geleneksel mühür, arma, sahte karakterli kırmızı kare.

04

Brush + Geometry

CORE IDEAOrganik jest × kesin geometri gerilimi: gelenek/gelecek, insan/yapı — etkileşimin kendisi kimlik.

MARK HYPOTHESISGeometrik çerçevede kesilen/tutulan jest çizgisi.

TYPE / COLORGrotesk yapı + tek ekspresif serif vurgu; mürekkep + kâğıt + sıcak vurgu.

ASIAN SOURCEFırça-ve-cetvel ikiliği: yöntem, motif değil.

STUDENT / PARENTDinamik, yönlendirilmiş / yöntemli ama insani.

MAIN RISKSwoosh klişesi / daire-üzeri-fırça mimarlık logosu. ASLA: jenerik swoosh, mimarlık logosu, systemsiz süs.

05

Typographic Asia

CORE IDEAASYA EĞİTİM adının kendisi kimlik: harf ilişkileri, boşluk ritmi, 1–2 özel harf; simge ikincil veya yok.

MARK HYPOTHESISKelime-mark geometrisinden türeyen küçük yapısal işaret (varsa).

TYPE / COLORDisplay-öncül yüksek yazarlık; mürekkep + kâğıt + karar sonrası tek vurgu.

ASIAN SOURCEYazı-sistemi kurma mantığı (parçalardan anlam), gerçek yazı ödünç almadan.

STUDENT / PARENTTasarım-okuryazar, modern / açık sözlü, premium.

MAIN RISKTasarlanmış yerine bozulmuş hissi. ASLA: novelty yazı, sahte-Asya harf bükme, CJK karakteri, okunmaz logo.

06

Open Character

CORE IDEADoğu Asya yazı kompozisyon mantığıyla soyut işaret: kare alan, çizgi hiyerarşisi, iç negatif, sıkışma-bırakma — gerçek karaktere benzemeden.

MARK HYPOTHESISCanlı negatif çekirdekli, 3–6 hiyerarşik çizgili sıkışık kare kompozisyon.

TYPE / COLORBilge serif + işlevsel sans/mono; mürekkep + kâğıt + derin vurgu.

ASIAN SOURCECJK kurma ilkeleri (çizgi hiyerarşisi, kare denge) — yöntem olarak.

STUDENT / PARENTAyırt edici rozet gururu / derin akademik güven.

MAIN RISKGerçek karakterle çakışma (üretim öncesi çarpışma kontrolü şart). ASLA: gerçek CJK, sahte mühür, jenerik kurumsal geometri.

07

Young Asia / New Academic

CORE IDEASeul–Tokyo–Şanghay–Singapur–Hong Kong öğrenci kültürünün enerjisi: parlak palet, güvenli tipografi, grafik bloklar, disiplinli oyun.

MARK HYPOTHESISCesur blok/harf-öncül işaret; çıkartma/hareket uyumlu sadelik.

TYPE / COLORÖzgüvenli grotesk/display; sıcak kâğıt + canlı vurgu + derin destek.

ASIAN SOURCEBeş pazarın güncel kampüs/şehir kültürü — miras değil.

STUDENT / PARENTHeyecanlı, görülmüş / modern (güven içerikle kazanılır).

MAIN RISKSaaS tekdüzeliği, trend avcılığı. ASLA: SaaS estetiği, TikTok-trend, uluslararası-okul mavisi, çocuksu grafik.

08

Future East

CORE IDEAMiras motifsiz ileri kimlik: keskin tipografi, olağandışı oran, grafik sıkıştırma, yüksek etkili tutumlu renk.

MARK HYPOTHESISTek fikre indirgenmiş minimal işaret (kesik, kayma, oran kırılması).

TYPE / COLORKeskin grotesk/display; mürekkep + kâğıt + tek elektrik vurgu.

ASIAN SOURCEGüncel Asya dijital/grafik kültürünün özgüveni — şimdiki zaman.

STUDENT / PARENTHırslı, seçici / ilerici ama disiplinli.

MAIN RISKCyberpunk/oyun/kripto okuması. ASLA: cyberpunk neon, oyun markası, kripto estetiği, jenerik teknoloji markası.
